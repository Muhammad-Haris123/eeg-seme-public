# Paper workspace (Computers in Biology and Medicine)

Follow `.cursor/rules/paper-writing-rules.mdc` for all drafting.

## Layout

```
paper/
  GROUND_TRUTH_SOURCES.md   # indexed validation + config paths (read first)
  citation_ledger.md
  figures_tables_manifest.md
  abbreviations.md
  references.bib
  sections/                 # 01_introduction.md, 02_methods.md, ...
  figures/                  # final numbered figure files
  tables/                   # final table sources
```

## Before writing any sentence

1. Open `GROUND_TRUTH_SOURCES.md`.
2. Pull numbers only from listed JSON/MD artifacts.
3. Log each new number in `citation_ledger.md`.
